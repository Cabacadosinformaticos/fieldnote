# Mockups

High-fidelity mockups of the participant app (Android, 412 x 915 dp) and of the researcher and
administrator portal (1440 px wide), rendered at 2x. The interface is in Portuguese. All data shown is
generated demonstration data; no real person appears. Status: proposed design, not implemented.
