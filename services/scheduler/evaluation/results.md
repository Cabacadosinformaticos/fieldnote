# Scheduler evaluation results

Generated by `uv run python -m scheduler.evaluation_suite`. Every number is deterministic for the same command except wall-clock times: `timings_ms` in `results.json` and every column marked machine-dependent. Those change between runs and machines.

Scheduler plans use the default `SearchOptions`; the node budget is per study. A run with `Finished = no` was cut by its node budget: it reports the best plan found, not a proven optimum.
